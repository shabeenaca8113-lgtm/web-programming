LISTS IN HTML

1.Ordered list

An ordered list is a list in which items are displayed in a specific order

Example

  1. Apple
  2. Orange
  3. Banana
  4. Grapes

2.Unordered list

An unordered list is a list in which items are displayed using bullet points

Example

  • Apple
  • Orange
  • Banana
  • Grapes

3.Description list

Description list is used to display terms along with their description
